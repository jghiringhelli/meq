# Code of Conduct

We want a friendly, harassment-free space for everyone who loves
*Middle-earth Quest*.

- Be respectful and constructive; criticize code and ideas, not people.
- No harassment, discrimination, or personal attacks.
- Assume good faith; this is a hobby project run in spare time.
- Do not share pirated game files, scans or copyrighted artwork.

Maintainers may remove comments, issues or PRs that violate this and may
block repeat offenders. Report problems by opening an issue or contacting the
maintainer (@jghiringhelli) on GitHub.
